🩺 Saúde do catálogo

Procura problemas no catálogo: filmes/episódios sem link, links com prefixo duplicado, caracteres invisíveis (os que o GitHub acusa) e capas faltando.

“Corrigir automático” remove prefixos repetidos e caracteres invisíveis. Antes de qualquer salvamento o painel guarda um backup no seu navegador.

🔑 GitHub (salvar catálogo)

O painel salva o catalog.json direto no seu repositório. A configuração fica só neste navegador.

🛡️ Proteções ativas

✔ Antes de salvar, o painel relê o catálogo do GitHub e só altera o item que você mexeu.
✔ Se o salvamento fosse apagar itens, ele cancela e avisa.
✔ Se o GitHub devolver o catálogo vazio, nada é salvo.
✔ Backup local automático antes de cada salvamento.
✔ Caracteres invisíveis são removidos automaticamente.
